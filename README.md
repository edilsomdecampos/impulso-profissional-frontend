# Impulso Profissional - Frontend

Frontend do projeto **Impulso Profissional**, desenvolvido em ReactJS com Vite.

## Sobre o projeto

O Impulso Profissional é uma plataforma voltada para adultos com 18 anos ou mais, com foco em empregabilidade e capacitação profissional.

ODS trabalhadas:

- ODS 8 - Trabalho Decente e Crescimento Econômico
- ODS 10 - Redução das Desigualdades

## Tecnologias

- ReactJS
- Vite
- JavaScript
- HTML
- CSS

## Funcionalidades

O frontend possui 3 CRUDs completos:

- Empresas
- Vagas
- Cursos

Cada módulo permite:

- Criar
- Listar
- Atualizar
- Excluir

## Componentização

A interface utiliza componentes reutilizáveis, como:

- Navbar
- Footer
- PageHeader
- Message

Páginas principais:

- Home
- Empresas
- Vagas
- Cursos

## Integração

O frontend consome a API Spring Boot em:

http://localhost:8080

## Como executar

Pré-requisitos:

- Node.js
- npm

Comandos:

npm install
npm run dev

Por padrão, a aplicação roda em:

http://localhost:5173
